## 🚀 راه‌اندازی روی Cloudflare Pages (از گیت‌هاب)

### ۱) پروژه را روی GitHub بگذار
این پوشه را unzip کن، بعد:
```bash
cd rol-invite-next
git init
git add .
git commit -m "rol-invite ❤️"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

### ۲) در Cloudflare Pages وصلش کن
1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. ریپو را انتخاب کن.
3. تنظیمات build (دقیقاً همین‌ها):

| فیلد | مقدار |
|---|---|
| Framework preset | **None** |
| Build command | `npm run build` |
| Build output directory | `out` |
| Root directory | `/` |

4. قبل از اولین deploy (یا بعدش، فرقی ندارد) دو **KV binding** اضافه کن:
   - **Settings → Functions → KV namespace bindings → Add binding**
   - اسم Variable: `CONFIG` → یک KV namespace جدید بساز (مثلاً `rol-config`) و انتخاب کن
   - دوباره Add binding → اسم: `STATS` → namespace جدا (مثلاً `rol-stats`)
   - Save و Retry deploy
5. (پیشنهادی) در **Settings → Environment variables**:
   - `ADMIN_PASSWORD` = یک رمز دلخواه برای پنل مدیریت (پیش‌فرض بدون آن: `rol-admin-1234`)
   - `NEXT_PUBLIC_SITE_URL` = آدرس سایتت مثل `https://rol.pages.dev` (برای کامل بودن پیش‌نمایش سوشال)

تمام! سایت روی `https://<project>.pages.dev` بالا می‌آید و از این به بعد هر push به main خودکار deploy می‌شود. 🎉

> **نکته:** پوشه‌ی `functions/` به‌صورت خودکار توسط Pages شناسایی می‌شود (API روی `/api/*`). فایل‌های `_headers` و `_routes.json` هم خودکار اعمال می‌شوند.

## 🔐 پنل مدیریت — `/admin`

**فقط برای خودت:** در تنظیمات Pages متغیر محیطی `ADMIN_PASSWORD` را با یک رمز قتی ست کن (تنها راه ورود). اگر ست نشود، رمزِ داخل خود پنل (بخش آمار ← کلید، پیش‌فرض `rol-admin-1234`) استفاده می‌شود و پنل هشدار می‌دهد که عوضش کنی. ۸ بار رمز اشتباه = قفل ۱۰ دقیقه‌ای.

چیزهایی که می‌توانی ویرایش کنی (همه با ذخیره‌ی زنده، بدون نیاز به deploy):

| بخش | چه چیزی |
|---|---|
| ⚙️ عمومی | اسم خودت، اسم او، سؤال اصلی، لقب بعد از بله، تم پیش‌فرض |
| 🎨 تم و رنگ | کد hex هر ۳ تم (روتیک/بنفش/شرابی) + پیش‌نمایش زنده |
| ✍️ متن‌ها | **تک‌تک جمله‌های سایت** (۶۸ متن) + پیام‌های دکمه‌ی «نه» |
| ☕ گزینه‌های قرار | افزودن/حذف/جابه‌جایی کارت‌ها با ایموجی و توضیح |
| 🕐 زمان و ساعت | گزینه‌های «حالا کِی؟» و ساعت |
| 📜 قرارداد | بندها (شماره‌گذاری خودکار) |
| 🕵️ پیام‌های مخفی | متن ۳ ایستر‌اگ |
| 🎵 موسیقی و استیکر | آدرس موسیقی با دکمه‌ی تست پخش + استیکر دلخواه برای هر ۶ جا |
| 📊 آمار | روشن/خاموش، نمایش یا هش‌شدن اسم‌ها، جدول تعداد جواب‌ها |
| 💌 پاسخ‌گویی | یوزرنیم تلگرام تو + متن پیام پیش‌فرض |
| 🔗 لینک و پیش‌نمایش | ساخت لینک با اسم + پیش‌نمایش زنده در iframe |
| 💾 پشتیبان‌گیری | دانلود/بازگردانی JSON همه‌ی تنظیمات + بازنشانی کامل |

- فقط **تغییرات** نسبت به پیش‌فرض ذخیره می‌شوند؛ اگر بعداً کد را آپدیت کنی، متن‌های جدید خودکار می‌آیند.
- همه‌ی ورودی‌ها سمت سرور whitelist و پاک‌سازی می‌شوند (بدون XSS).
- تأیید ذخیره: بعد از Save، لینک دعوت‌نامه را در مرورگر دیگر باز کن — تغییرات باید نمایان باشند.

## 🛡️ نکات امنیتی و فنی

- کانفیگ KV **عمومی خواندنی** است ولی متن‌ها همانی است که خودت می‌خواهی او ببیند؛ **نوشتن فقط با رمز** ممکن است.
- پارامتر `?name=` کامل sanitize می‌شود (فارسی/انگلیسی/نیم‌فاصله اوکی؛ تگ و اسکریپت حذف).
- آمار فقط «تعداد رویداد» ذخیره می‌کند — بدون IP، بدون کوکی؛ اسم‌ها به انتخاب خودت هش می‌شوند.
- هدرهای امنیتی (`nosniff`, `no-referrer`, `Permissions-Policy`) + کش immutable برای استیکرها/فونت.
- استاتیک کامل (خروجی `out/`) — سریع، ارزان و مقیاس‌پذیر؛ فقط `/api/*` روی edge اجرا می‌شود.
- `prefers-reduced-motion` کامل پشتیبانی می‌شود؛ موبایل‌فرست با safe-area برای آیفون.

## ❓ رفع اشکال

| مشکل | راه‌حل |
|---|---|
| پنل می‌گوید «KV وصل نیست» | Settings → Functions → KV bindings → دقیقاً `CONFIG` (و برای آمار `STATS`) |
| تغییرات ادمین ذخیره نمی‌شود | رمز درست است؟ (env `ADMIN_PASSWORD` یا پیش‌فرض) — بعد از Save پیام سبز باید بیاید |
| `/api/*` چهل‌چهارمی می‌دهد | مطمئن شو پوشه‌ی `functions/` ریشه‌ی ریپو است و preset روی **None** است |
| فونت/استیکر لود نمی‌شود | خروجی باید `out` باشد؛ فایل‌های `public/assets` باید در ریپو باشند |
| پیش‌نمایش سوشال (og) ناقص | `NEXT_PUBLIC_SITE_URL` را ست کن و مجدد deploy کن |
