# مخ‌یار — همراهِ مخ زدن

اپ فارسی/RTL و **PWA نصب‌شدنی** با طراحی دارکِ گلاس، آیکون‌های SVG (بدون ایموجی) و فونت متغیر وزیرمتن؛ ۵ تب: **خانه**، **چت‌یار** (۵ ابزار: پاسخ/شروع/بازنویسی/تحلیل/قرار)، **ساخت درخواست**، **تاریخچه** و **تنظیمات**.

ساخته‌شده با ❤️ و کمی جسارت توسط **اَوید کیا** — [@AvidKiya](https://t.me/AvidKiya)

## ✨ امکانات

- 👤 **ثبت‌نام/ورود**: حساب شخصی با توکن ۳۰ روزه + **کد بازیابی** و حذف کامل حساب؛ پروفایل با اسم، کرش‌های چندتا، جنسیت و سبک چت
- 🔌 **اتصال یک‌کلیکی با اکانت (OpenRouter PKCE)**: بدون کلید و API — دکمه را بزن، با گوگل لاگین کن، تمام؛ کلیدِ ساخته‌شده فقط روی سرور خودت می‌ماند و قابل قطع است. (اتصال با اکانت ChatGPT از سمت OpenAI به اپ‌های ثالث مجاز نیست؛ کلید دستی ChatGPT هم به‌عنوان گزینه‌ی پیشرفته هست)
- **چت‌یار با کلید API خودت**: کلید ChatGPT خودت را در تنظیمات می‌گذاری — کلید فقط سمت سرور می‌ماند و صرفاً پروکسی می‌شود (پرومپت سیستمی فارسی مخ‌یار). پشتیبانی از **بینایی**: تا ۲ اسکرین‌شات استوری/چت
- **۶ ابزار**: پاسخ هوشمند، پیام شروع‌کننده، بازنویسی پیش‌نویس، تحلیل پروفایل/چت، ایده قرار، **شبیه‌ساز کرش** — با چیپ‌های سناریو + **پاسخ استریم زنده** و **حافظه‌ی گفتگو**
- **۹ لحن**: بامزه، رمانتیک، ادبی، مستقیم، مرموز، خونسرد + سه لحن بزرگسال
- **فضای بزرگسال (+۱۸)**: با دروازه‌ی سن (شمسی/میلادی) و ۱۴ علاقه‌مندی از جمله BDSM و فتیش‌ها؛ لحن‌های +۱۸ تا تأیید سن قفل‌اند و پرامپت‌ها رضایت‌محور و بدون صراحت نگه داشته می‌شوند
- 🎨 **ساخت درخواست**: ۴ مناسبت با متن کامل اختصاصی (رل زدن، خواستگاری/ازدواج، دوستی، همکاری)، شعرهای اصیل ایرانی، دکمه‌ی «نه» که قلقلک می‌خورد، ۶ تم رنگی، کارت خروجی PNG، لینک با اسم فارسیِ خام
- 🗂️ **تاریخچه**: چت‌ها و دعوت‌نامه‌های ساخته‌شده با تاریخ شمسی
- 📲 **PWA**: روی گوشی نصب می‌شود (Add to Home Screen) و آفلاین باز می‌شود
- 🛡 امنیت: رمز PBKDF2، قفل بعد از خطای مکرر، ریت‌لیمیت API، سنیتیزه‌ی ورودی‌ها، بدون HTML تزریقی
- ♿️ ریسپانسیو کامل (۳۲۰px تا دسکتاپ)، احترام به prefers-reduced-motion

## 🚀 دیپلوی روی Cloudflare Pages (۳ دقیقه)

1. ریپو را push کن و در Pages متصلش کن (یا ZIP را مستقیم آپلود کن)
2. Framework: **None** · Build command: `npm run build` · Output: `out`
3. دو KV namespace بساز و به نام‌های `CONFIG` و `STATS` وصل کن (اختیاری ولی پیشنهادی)
4. متغیر محیطی `ADMIN_PASSWORD` را با رمز قوی ست کن → پنل `/admin` فقط مال توست
5. (اختیاری) `NEXT_PUBLIC_SITE_URL=https://دامنه‌ات` برای لینک‌های مطلق اشتراک‌گذاری

بدون KV هم همه‌چیز کار می‌کند (فقط ذخیره‌ی تنظیمات و آمار غیرفعال است).

## 🛠 توسعه

```bash
npm install
npm run dev        # توسعه‌ی محلی Next.js
npm run preview    # شبیه‌سازی کامل Pages + KV محلی (wrangler)
npm test           # ۱۲۰+ تست E2E واقعی (پیش‌نیاز: npx playwright install chromium)
npm run build      # بیلد استاتیک → out/
```

### ساختار پروژه
```
app/                صفحات (لندینگ /، دعوت /invite، دمو /demo، ادمین /admin)
components/         Experience.jsx (ماشین وضعیت صفحات)، Landing، AdminPanel، Sticker
lib/                core (متن/وضعیت/آمار) · card (کارت canvas) · fx · stickers · occasion
shared/             config.mjs (تمام متن‌ها و تنظیمات پیش‌فرض) · validate.mjs
functions/api/      Pages Functions (config/event/stats) — _lib/ تولیدشده است، دستی تغییر نده
public/assets/      استیکرها · موزیک · فونت وزیرمتن · آیکون‌ها
scripts/            test-flows.mjs (تست E2E) · sync-shared · render-card · make_music
docs/shots/         اسکرین‌شات‌های نسخه‌ی جاری
```

### کارهای رایج
- **متن جدید/ویرایش**: `shared/config.mjs` → `text` (یا از پنل ادمین در زمان اجرا)
- **مناسبت جدید**: به `occasions` اضافه کن — `pack` متن‌های اختصاصی، `verses` ابیات (آرایه‌ی `[مصرع۱، مصرع۲]`)، `sticker` نام استیکر
- **تم جدید**: کلید جدید در `themes` با `bg/bg2/acc/acc2/glow`
- **موزیک**: فایل mp3 در `public/assets/music/` و آدرسش در پنل یا config
